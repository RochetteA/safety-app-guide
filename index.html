How to change things in the safety app

Step by step instructions for adding buttons, labels, pages, phone numbers, emails and links. No coding, and nothing goes through the App Store.

Start here

What the editing screen is, and how the app is put together.

Getting in

  1. On a computer, go to macewan.apparmor.com. The editing screen puts a live phone preview beside your work, so it needs a wide screen.
  2. Click Sign in with MacEwan Credentials, or use the username and password from your app administrator. There is a Forgot Password? link on the same screen.
  3. Open the Content Management tab, then click Designer. That is where every instruction on this site takes place.

Every button in the app, listed out. Click one to select it. This is how you get around.

Properties

Middle

The settings for whichever button you clicked: its wording, what it does, its icon, whether it is visible.

App preview

Far right

A live picture of the app. It refreshes when you save, or when you click a different button in the tree. On a narrow screen there is a button that slides it out from the right edge.

Saving and publishing

Save Properties

Nothing saves on its own. Click Save Properties after each thing you change. Clicking away from a button before saving loses what you typed.

Draft Mode

Draft Mode holds your changes back so they are not visible in the app yet. Publishing releases them. Published changes reach phones in real time, with no App Store submission and no waiting on IT.

How the app is put together

The app is a tree of buttons. The home screen is a list of buttons. Tapping one either opens another list of buttons, or does one specific thing.

Every job on this site is the same job: find the right spot in the tree, add or change a button, tell it what to do, save, publish, test.

Where these pages name an option in the Designer, it is marked like check the wording. AppArmor does not publish their dropdown names, so those few labels may read slightly differently in your dashboard. What each option does is correct, so pick by meaning.

How to add a button

The one you will use most. Everything else here is a variation of it.

  1. In the Designer, click the list you want the button to sit inside, using the menu tree on the left. New buttons are added inside whatever is selected, so select the parent first. To put a button on the home screen, click the very top level.
  2. Click the control that adds a new item check the wording. A new blank button appears in the tree.
  3. Type the wording people will see on the button.
  4. Choose what the button does from the dropdown. There are five choices, each with its own section on this site:
    • opens a list of more buttons
    • opens a page of information
    • dials a phone number
    • sends an email
    • opens a web page
  5. Fill in the matching box: the number, the email address, the web address, or the page content.
  6. Pick an icon if the Properties panel offers one, and check that the button is set to visible.
  7. Click Save Properties.
  8. Look at the app preview on the right to check the wording is not cut off and the button is where you expected. Drag it into position if not.
  9. Publish it, then test it on a phone. Both are under Publish and test.

How to add a label

The wording on a button, and headings inside a page.

The wording on a button

  1. In the menu tree, click the button you want to name or rename.
  2. In the Properties panel, find the box that holds the button's wording check the wording.
  3. Type the label.
  4. Click Save Properties.
  5. Check the app preview. Labels that do not fit on one line are cut off, and smaller phones cut off sooner than the preview does.
  6. Publish and test.

A heading inside a page

  1. Click the button whose page you are adding a heading to.
  2. In the content editor, put your cursor where the heading goes and type it.
  3. Select the text you just typed, then choose a heading style from the editor's formatting menu.
  4. Use the heading style rather than making text bold and large. The heading style is what lets a screen reader announce it as a heading.
  5. Click Save Properties, then check the page in the preview.
  6. Publish and test.

How to add a page

A page of information inside the app.

  1. Add a button in the list where you want it, following the Add a button steps.
  2. Choose the option that opens a page of content check the wording.
  3. Open the content editor in the Properties panel. It works like a simplified Word: bold, bullets, headings, images and video.
  4. Type or paste your content. If you are copying from Word, paste as plain text and then apply the formatting inside the editor. Pasting straight from Word brings hidden styling with it, which changes how the page lays out on a phone.
  5. Click Save Properties.
  6. Read the page in the app preview at phone width.
  7. Publish and test.
Worth knowing

Content pages are stored in the app itself, so they still open when the phone has no signal. Web links do not.

How to add a phone number

A button that starts dialling when tapped.

  1. Add a button in the list where you want it.
  2. Type the label, for example Call Security Services.
  3. Choose the option that places a call check the wording.
  4. Type the number with no spaces, dashes or brackets, and with the country code on the front:
    • Right: +17804975555
    • Wrong: 780-497-5555
    • Wrong: (780) 497 5555
    Punctuation and a missing country code are the usual reason a call button does nothing.
  5. For an extension, try a comma pause: +17804975555,,412. If the box will not accept it, put the extension in the button label instead.
  6. Click Save Properties.
  7. Publish, then place the call from a phone to confirm it connects.

How to add an email

A button that opens a new email, already addressed.

  1. Add a button in the list where you want it.
  2. Type the label, for example Email the Wellness Team.
  3. Choose the option that sends an email check the wording.
  4. Type the destination address.
  5. If there is a subject line box, fill it in. If there is a message body box, you can leave it empty or add starting text.
  6. Click Save Properties.
  7. Publish, then send a test email from a phone and confirm it arrives.

How to add a web link

A button that opens a web page.

  1. Open the page in a browser and copy the address out of the address bar. Typing it from memory is the most common cause of a broken link.
  2. Add a button in the list where you want it and type the label.
  3. Choose the option that opens a link check the wording.
  4. Paste the full address, including the https:// at the front.
  5. If you are offered a choice between opening inside the app or in the phone's browser, pick one. Pages with a login or a form usually work better in the browser.
  6. Click Save Properties.
  7. Publish, then tap it on a phone and confirm the page loads and reads properly at phone width.
Worth knowing

A web link needs a working signal. It will not open when the phone is offline.

How to link to another spot in the app

Two ways: a button that opens a list, and a shortcut to something that already exists.

A button that opens a list

  1. Add a button where you want the doorway to be.
  2. Choose the option that opens a submenu or folder check the wording.
  3. Click Save Properties. You now have an empty list.
  4. With that button still selected in the tree, add the buttons that belong inside it. They appear underneath it, indented.
  5. Save, publish, then tap through from the home screen to test.

A shortcut to something that already exists

  1. Add a button where you want the shortcut.
  2. Look in the Properties panel for an option that points at an existing item or internal page check the wording.
  3. If it is there, choose it and pick the destination. That gives you one page reachable from two places, so you only update it once.
  4. If there is no such option, the only alternative is a second copy of the page, which then has to be updated in both places every time it changes.
  5. Save, publish, then tap through from both directions to test.

How to add a picture

Images and video inside a page.

  1. Resize the file before uploading. Around 1000 pixels wide is plenty. Full size photos straight off a camera or phone make the page slow to load.
  2. Click the button whose page you are adding to, and open the content editor.
  3. Use the image or media control to upload the file.
  4. Add alternative text describing what the image shows, so it works for anyone using a screen reader.
  5. Click Save Properties.
  6. Check it in the app preview, then on a phone. For maps and floor plans, check that pinch to zoom works and the labels stay readable.
  7. Publish and test.
Worth knowing

Video streams from the internet, so it will not play when the phone is offline. Uploaded images are stored in the app and will still show.

How to move, hide or delete a button

Move a button

  1. In the menu tree, drag the button up or down into position, or use the ordering control in Properties check how yours works.
  2. Click Save Properties.
  3. Check the order in the app preview, then publish and test.

Hide a button

  1. Click the button, then switch its visibility off check the wording.
  2. It disappears from the app but stays in your dashboard, so switching it back on takes one click.
  3. Click Save Properties, publish, then confirm on a phone that it is gone.

Delete a button

  1. Copy the page text somewhere else first. Deleting is not reversible, and getting content back means a support ticket.
  2. Delete the button, then click Save Properties.
  3. Publish, then check the surrounding list on a phone in case anything else shifted.

How to publish and test

The last step of every job on this site.

Publish

  1. Check that everything you changed has been saved with Save Properties.
  2. Walk through the section you changed in the app preview.
  3. Publish the change check the wording and where the control sits. It reaches phones in real time.
  4. Test it using the checklist below.

Test on a phone

  • Force close the app and reopen it, so it pulls the fresh content.
  • Find your change by navigating from the home screen.
  • The wording fits on one line and is not cut off.
  • Tap it, and it does what it says.
  • Phone buttons: place the call and confirm it connects.
  • Email buttons: send a test and confirm it arrives.
  • Web buttons: the page loads and reads properly at phone width.
  • Pages: read the whole page on the phone, checking for broken images.
  • Check on both an iPhone and an Android phone, since they lay things out differently.
  • Turn on airplane mode and check that your content pages still open.
  • Nothing else moved or disappeared.

How to undo something

  1. Change the field back to what it was and publish again.
  2. For something you cannot fix by editing, such as a deleted page you need back, raise a ticket on the dashboard's Support page.

If it goes wrong

The common problems and what fixes them.

What you are seeingUsually becauseDo this
Change is not showing on the phone The app is still holding the old content Force close the app and reopen it. If it still does not show, check that you published rather than only saving.
Change is not showing in the preview It was not saved Click Save Properties. The preview refreshes when you save, or when you click a different button in the tree.
Call button does nothing The number has punctuation in it Remove spaces, dashes and brackets, and put +1 on the front.
Web link opens a blank page The address was typed, or is missing https:// Open the page in a browser and copy the address out of the address bar.
Page looks broken or oddly spaced Text was pasted straight from Word Clear the formatting, paste again as plain text, then format inside the editor.
Label is cut off on some phones It is too long Shorten it and check the preview again.
You cannot find a setting described here Different permission level, or different wording in your dashboard Check with your app administrator, then use the dashboard's Support page.

Where to get more help

  • The dashboard's Support page. Inside the AppArmor dashboard. It has video training on the app and the dashboard, release notes covering platform updates every week or two, and a form for raising a ticket.
  • A support ticket. Raised on that same page. Use it for anything you cannot change yourself: the app icon, the app name, turning whole features on, and recovering deleted content.
  • Your app administrator for logins, permissions and single sign on.
